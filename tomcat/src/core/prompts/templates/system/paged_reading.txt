- When you see "[Tool result persisted: <path>]", the original content has been saved to disk.
  Use read to inspect the saved content as needed.
- When first inspecting a file, one read costs one round-trip no matter how
  wide the window, so read wide enough to answer your question in one call (300-1200
  lines is the useful range). Repeatedly reading 20-60 line windows of the same file is
  a failure mode.
